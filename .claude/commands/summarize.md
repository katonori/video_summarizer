---
description: YouTubeビデオをトピックごとに要約し、スクリーンショット付きHTMLレポートを生成
---

引数として渡された YouTube の URL（と、クッキーファイルのパスが指定されていれば
それも）を使って、以下をすべて自分で実行し完結させること。ユーザーにファイルの
アップロードや中間ファイルの受け渡しなど手作業をさせないこと。

対象URL: $ARGUMENTS

## 手順

### 1. フェーズ1スクリプトを実行（ダウンロード・文字起こし・トピック分割）

```bash
cd /home/user/video_summarizer
python3 summarize_prepare.py "<URL>" [--cookies <cookie_file>]
```

`draft-<タイトル>.json` が生成される。
`Sign in to confirm you're not a bot` のようなエラーが出た場合は、
ユーザーにクッキーファイル（cookies.txt）のパスを尋ねて `--cookies` を付けて
再実行する。

### 2. 下書きJSONを読み、要点を自分で書き込む

生成された `draft-*.json` を読む（サイズが大きい場合は `image` フィールドを
除いて読むか、`topics[].transcript` だけを抽出して読む）。

各トピックについて、**`transcript` の生の発言をそのまま引用するのではなく**、
内容を理解した上で3〜4個の高レベルな要点（日本語、簡潔な文）を考え、
そのトピックの `"points": null` を実際のリスト
`"points": ["要点1", "要点2", "要点3"]` に書き換える。全トピック分埋めるまで
繰り返す。

要点を書くときの基準:
- 誰が何と言ったかの引用ではなく、「何が起きている／何が主張されているか」を
  まとめ直す
- 各トピック内で異なる観点をカバーする（同じ内容の言い換えを繰り返さない）
- 数字・固有名詞・具体的な結論など、情報として意味のある部分は残す

### 3. フェーズ2スクリプトを実行してHTMLを生成

```bash
python3 finalize_report.py "draft-<タイトル>.json"
```

`points` が埋まっていないトピックがあるとエラーになるので、その場合は手順2に
戻って埋め切る。

### 4. 完了報告

生成された `report-*.html` のパスをユーザーに伝える。
